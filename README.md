En este proyecto se parte de un diseño en vivado para la FPGA ARTY Z7 20, donde se mide un dato en uno de los canales del xadc, para leer el dato del canal del xadc, no se usa un navegador con jupyter, como es común, si no, se diseño un script en python que se comunica con la FPGA usando protocolo SSH y ejecutando comandos de python para leer y escribir los registros de la FPGA. Con LabVIEW y usando estos scripts de python se puede hacer un instrumento virtual que visualiza la toma de datos.

Los pasos para comunicar la FPGA con LabVIEW se describen en el archivo Programando Arty con Linux.ipynb
